# 被叫姓名检测规格说明

<!-- doc-verified: initial -->

MeetingQ 的核心功能：会议中有人叫到你的名字时第一时间提醒。三层检测管道，兼顾速度与准确率。

## 三层管道

| 层级 | 技术 | 耗时 | 作用 |
|---|---|---|---|
| 0 | 本地正则（姓名/昵称/ASR 变体）+ 拼音/粤拼模糊匹配 | <50ms | 精确命中与同音误读 |
| 1 | 中文疑问句/指向性模式（"你觉得呢"、"你来负责"） | <200ms | 无点名但明显指向 |
| 2 | LLM 语义分析（结合姓名/角色） | 1–3s | 最终裁决 + 提取具体问题 |

流程：`detect()` 同步跑 0→1 层；命中后 `detectAsync()` 再进 2 层做语义确认与问题提取。层 0 拼音/粤拼命中的新变体通过 `autoAddAsrVariant` 自动学习，下次走快速通道。

## 编号边界 case

检测：

- **D1** 层 0 正则命中即返回，不再跑层 1；层 2 只做确认与问题提取，不推翻层 0 的命中
- **D2** 拼音/粤拼变体命中后自动加入 ASR 变体表；用户改名/改昵称后 `reloadNames()` 重建正则
- **D3** 姓名少于 2 个字不参与模糊匹配（防止"伟"误伤"伟大"）
- **D4** 层 2 不可用（无 LLM 配置/超时）时，层 0/1 的命中照常提醒——提醒可以糙，不能没有

提醒节流与展示：

- **A1** 两次提醒最小间隔 5 秒（`lastNameAlertFiredAt`），连续被叫不轰炸
- **A2** 弹窗内容 = 原话 + 前后 8 条上下文 + AI 提取的问题 + 即时截图；截图失败不阻塞弹窗
- **A3** 层 2 未提取到问题时，退化为展示原话本身
- **A4** 命中自己轨的发言（自己叫自己名字/复述）——由上层双轨隔离保证，检测层不区分轨

回声与重复：

- **E1** 麦克风轨复述系统轨的内容（外放回声）在转写入库前被 `isEchoOfRemote` 丢弃（12s 窗口、归一化编辑距离 ≥0.8），回声永远不进入检测管道
- **E2** 归一化文本 <4 字不参与回声判定（"好的"、"嗯"太容易误撞）

## 测试要求

- 层 0：精确名/昵称/同音变体/2 字下限（D3）
- 节流：5s 内重复命中只弹一次（A1）
- 降级：LLM 不可用时层 0 命中仍弹窗（D4）
